# Лабораторная работа № 2: Основы HTML и CSS

## Описание проекта
В рамках данной лабораторной работы разработан многостраничный web-сайт, посвященный легенде о Робин Гуде. Проект рассказывает историю знаменитого благородного разбойника из Шервудского леса и представляет ретроспективу его главных кинематографических и телевизионных адаптаций — от классики Золотого века Голливуда до современных блокбастеров.

Сайт состоит из трех логически связанных страниц:
1. **Главная страница (`index.html`)** — введение в историю персонажа.
2. **Экранизации (`adaptations.html`)** — подробный список адаптаций с постерами и кратким описанием.
3. **Таблица фильмов (`table.html`)** — сводная таблица всех рассмотренных картин для удобного сравнения.

## Что было проделано
Проект выполнен в строгом соответствии с требованиями лабораторной работы:
* **Структура:** Создано 3 HTML-страницы, объединенные общим навигационным меню.
* **HTML-разметка:** Применены различные блочные (заголовки, абзацы, списки, `div`) и строчные (`span`, `b`) элементы.
* **Медиа и навигация:** На страницы добавлены изображения (постеры фильмов) и гиперссылки для перехода между разделами сайта.
* **Табличные данные:** Сверстана таблица с использованием различных видов выравнивания текста в ячейках (по левому краю, по центру, по правому краю).
* **Стилизация (CSS):** Все стили вынесены в отдельный подключаемый файл `style.css`.
* **Селекторы и оформление:** В CSS-файле использовано более 3 видов селекторов (селекторы тегов, классов, идентификаторов, селекторы потомков и псевдоклассы). Настроена цветовая палитра для текста и фона.
* **Ограничения:** Проект реализован исключительно на чистом HTML и CSS. Сторонние библиотеки, фреймворки (например, Bootstrap) и JavaScript не использовались.

## Запуск проекта
Для просмотра сайта достаточно скачать репозиторий (или переключиться на ветку `lab2`) и открыть файл `index.html` в любом современном веб-браузере.

## Лабораторная работа № 3: Основы JavaScript

### Описание проекта
В рамках данной лабораторной работы изучены базовые и продвинутые концепции языка программирования JavaScript. Работа выполнялась на основе предоставленного каркаса проекта (Node.js) с использованием системы автоматического тестирования.

### Что было проделано
Проект выполнен в соответствии с требованиями к лабораторной работе:
* **Настройка окружения:** Каркас проекта успешно перенесен в локальный репозиторий (в ветку `lab3`), установлены зависимости проекта с помощью пакетного менеджера npm (`npm install`).
* **Реализация базовых алгоритмов:** В файле `src/core.js` написаны функции, использующие побитовые операции (`isInteger`, `isBinary`), циклы (`even`, `sumTo`, `fibonacci`) и рекурсию (`recSumTo`, `factorial`).
* **Продвинутые концепции JS:** 
  * Реализованы функции, использующие концепцию замыканий (closures) и лексического окружения для сохранения состояния (`getOperationFn`).
  * Создана функция-генератор последовательностей с использованием параметров по умолчанию (`sequence`).
* **Глубокое сравнение объектов:** Написана функция рекурсивного глубокого сравнения объектов `deepEqual`. При реализации учтены особенности преобразования типов JavaScript (включая проверку на `NaN`, так как `NaN === NaN` возвращает `false`).
* **Тестирование:** Код успешно прошел все автоматизированные тесты (16 passing) с использованием команды `npm test`.

### Как запустить тесты локально
1. Убедитесь, что у вас установлен [Node.js](https://nodejs.org/).
2. Откройте терминал в папке проекта (`lab3`).
3. Установите зависимости: `npm install`
4. Запустите тесты: `npm test`
